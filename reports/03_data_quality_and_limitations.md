## UAE 처리

노트북 실행 로그에서 UAE는 2020-2024년 모든 연도에 대해 `no data or error`가 발생했다.

처리 원칙은 다음과 같다.

- 재호출로 API 일시 오류 여부를 먼저 확인
- 반복 실패 시 `missing_due_to_api_error`로 별도 표시
- 정량 분석의 핵심 결론에서는 제외
- 보고서에는 해석 보류 국가로 명시

## 조지아 처리

조지아는 증가율 기준으로는 크게 보이지만 대부분 월이 결측이다. 제재 전 값이 0이고 제재 후 일부 월만 관측될 경우 증가율이 과대 계산될 수 있다.

따라서 조지아는 다음처럼 처리하는 것이 적절하다.

- 핵심 결론에는 포함하지 않음
- 보조 사례 또는 추가 검증 대상국으로만 언급
- 원천 API 재수집 또는 다른 데이터 소스와 교차 검증 필요

## 증가율 해석 주의

노트북에서는 `post_pre_ratio = (post + 1) / (pre + 1)` 방식으로 0 나눗셈을 회피했다. 이 방식은 제재 전 수출액이 0에 가까운 국가에서 증가율이 매우 크게 나타날 수 있다.

따라서 증가율만으로 판단하지 않고 다음 지표를 함께 봐야 한다.

- 제재 후 월평균 절대 규모
- 절대 증가액
- 관측 개월 수
- 제재 전 기존 거래 규모
- 국가별 API 수집 실패 여부

## HS 코드 버전 불일치 문제

### 배경

HS 코드는 세계관세기구(WCO)가 5년마다 개정한다. 현재 최신 버전은 HS 2022(H6)이며, 이전 버전은 HS 2017(H5)이다.

| 버전 | 적용 시점 | UN Comtrade 표기 |
|------|----------|-----------------|
| HS 2017 | 2017년~ | H5 |
| HS 2022 | 2022년~ | H6 |

### 문제 발생 조건

2022년을 기점으로 UN Comtrade 데이터의 분류 기준이 H5 → H6으로 바뀐다. 이 분석의 대상 기간(2020~2024년)이 이 전환 시점을 포함하기 때문에 **6단위 이하 세부 코드 수준에서는 연도 간 직접 비교가 불가**하다.

예시: HS 8542(전자 집적회로) 6단위 변화

| 품목 | HS 2017 (H5) | HS 2022 (H6) |
|------|-------------|-------------|
| 프로세서·컨트롤러 | `854231` | `854231` (유지) |
| 메모리 | `854232` | `854232` (유지) |
| 기타 집적회로 | `854290` (1개) | `854241`, `854249`, `854251`, `854259`, `854261`, `854269`, `854290` (7개로 세분화) |

H5에서 `854290 기타` 하나였던 항목이 H6에서 7개로 쪼개졌다. `854290`만 추적하면 2022년 이후 수출이 급감한 것처럼 보이지만 실제로는 코드가 분산된 것이다.

### 현재 분석에서의 영향

이 노트북은 `cmdCode='7210'`, `cmdCode='8542'`로 **2단위 수준**에서 조회했다. 2단위 코드는 HS 개정 시에도 거의 변경되지 않으므로 2020~2024년 시계열 비교에 문제가 없다. 수집 결과에서 `isAggregate=True`로 나타나는 것도 이 때문이다.

### 6단위 분석 시 필요한 작업

향후 세부 품목별 분석을 위해 6단위로 조회할 경우 반드시 아래 작업이 필요하다.

1. UN Comtrade 응답의 `classificationCode` 컬럼으로 각 행의 HS 버전 확인
2. WCO 상관표(correlation table)를 이용해 H5 → H6 코드 매핑
3. 버전이 다른 연도 간 비교 시 매핑된 코드 기준으로 재집계

```python
# 버전 확인 예시
df["classificationCode"].value_counts()
# H5: 2020~2021년 데이터
# H6: 2022년 이후 데이터
```

## 추가 검증 필요 사항

- UAE 데이터 미수집이 실제 무역 없음인지 API 오류인지 구분
- `Türkiye`와 `Turkey` 국가명 표준화가 전체 데이터에 일관되게 적용되는지 확인
- `isReported=False` 행이 포함된 경우 파트너 보고 데이터인지 여부를 분석 해석에 반영
- HS 8542와 HS 7210 외 통제 품목을 추가해 제재 효과와 일반 무역 변동을 구분
- 월별 이상치가 평균을 과도하게 끌어올렸는지 중앙값 또는 분위수로 재검토
