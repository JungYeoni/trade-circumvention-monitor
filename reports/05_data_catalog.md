# 데이터 카탈로그

## 개요

이 문서는 프로젝트에서 확인된 로컬 데이터 파일과 노트북/API를 통해 생성되는 논리 데이터셋을 정리한다.

데이터 저장 경로는 `configs/base.yaml` 기준으로 다음과 같다.

| 구분 | 경로 | 용도 |
|---|---|---|
| Raw | `data/raw` | 원천 데이터 보관 |
| Interim | `data/interim` | 수집·전처리 중간 산출물 |
| Processed | `data/processed` | 분석·모델링용 최종 데이터 |
| Reports | `reports` | 분석 결과 문서 |

## 로컬 원천 데이터

### 산업통상부 무역구제 덤핑방지 관세 부과 현황

| 항목 | 내용 |
|---|---|
| 파일 | `data/raw/산업통상부_무역구제 덤핑방지 관세 부과 현황_20251231.csv` |
| 형식 | CSV |
| 인코딩 | CP949 |
| 행 수 | 160 |
| 컬럼 수 | 6 |
| 결측 | 확인된 결측 없음 |
| 기준일 | 파일명 기준 2025-12-31 |
| 성격 | 한국의 덤핑방지 관세 부과 이력 원천 데이터 |

#### 컬럼 정의

| 컬럼 | 타입 | 결측 수 | 고유값 수 | 설명 |
|---|---|---:|---:|---|
| `국가명` | 문자열 | 0 | 53 | 관세 부과 대상 국가 또는 국가 묶음 |
| `품목` | 문자열 | 0 | 120 | 덤핑방지 관세 부과 대상 품목명 |
| `관세부과범위` | 문자열 | 0 | 138 | 관세율, 가격약속, 기준가격 차액 등 부과 방식 |
| `부과시작일` | 문자열 | 0 | 129 | 관세 부과 시작일 |
| `부과종료일` | 문자열 | 0 | 127 | 관세 부과 종료일 |
| `관련법령` | 문자열 | 0 | 156 | 고시, 공고, 대통령령 등 법령 근거 |

#### 예시 값

| 국가명 | 품목 | 관세부과범위 | 부과시작일 | 부과종료일 | 관련법령 |
|---|---|---|---|---|---|
| 일본,대만 | D.C.P | 가격약속 | 1989-01-13 | 1989-12-31 | 재무부 공고 제89-2호 |
| 프랑스 | 알루미나 시멘트 | 가격약속 | 1989-09-01 | 1991-08-30 | 재무부 고시 제89-14호 |
| 미국,일본 | 폴리아세탈수지 | 기준가격과 수입가격의 차액 | 1991-09-30 | 1993-08-30 | 대통령령 제13467호 |

#### 사용상 주의

- 날짜 컬럼은 현재 문자열로 읽힌다. 분석 시 `datetime64`로 변환하는 것이 좋다.
- `국가명`에는 `일본,대만`처럼 복수 국가가 하나의 셀에 들어간 값이 있다.
- `관세부과범위`는 숫자 관세율과 `가격약속` 같은 텍스트가 혼재한다.
- 프로젝트 핵심 분석인 대러 우회 수출 분석과 직접 결합하려면 품목명-HS 코드 매핑이 추가로 필요하다.

## API 기반 논리 데이터셋

### UN Comtrade 월별 대러 무역 데이터

| 항목 | 내용 |
|---|---|
| 생성 위치 | `notebooks/제재_이후_특정_제_3국의_대리_수출이_구조적으로_증가했는가.ipynb` |
| 수집 함수 | `src/data/comtrade_client.py::collect_russia_trade()` |
| 원천 | UN Comtrade API |
| 인증 | `.env`의 `COMTRADE_API_KEY` |
| 기간 | 2020-01-2024-12 |
| 상대국 | 러시아, `partnerCode=643` |
| 보고국 | Armenia, Kazakhstan, Georgia, Turkey/Türkiye, UAE |
| 품목 | HS 7210, HS 8542 |
| 흐름 | 수출 `X`, 수입 `M` |
| 주요 금액 컬럼 | `primaryValue` |
| 현재 로컬 저장 여부 | 저장 파일 확인되지 않음 |

#### 주요 컬럼

| 컬럼 | 설명 |
|---|---|
| `reporterDesc` | 보고국명 |
| `reporterName` | 수집 함수에서 추가한 보고국명 |
| `partnerDesc` | 상대국명 |
| `cmdCode` | HS 품목 코드 |
| `flowCode` | 수출입 구분 |
| `refYear` | 기준 연도 |
| `refMonth` | 기준 월 |
| `primaryValue` | 분석용 금액 |
| `isReported` | 직접 보고 여부 |
| `isAggregate` | 집계 데이터 여부 |

#### 파생 데이터셋

| 데이터셋 | 생성 방식 | 목적 |
|---|---|---|
| `ts` | HS 7210, 8542 필터링 후 `date` 생성 | 시계열 분석 입력 |
| `ts_group` | 국가·품목·흐름·월 기준 `primaryValue` 합계 | 월별 수출입 추이 |
| `ts_x` | 수출 `flowCode="X"`만 필터링 | 제재 전후 대러 수출 비교 |
| `summary_pivot` | 제재 전후 월평균과 증가율 계산 | 국가별 구조 변화 비교 |
| `missing_summary` | 기대 월별 패널과 실제 관측치 비교 | 결측 진단 |

#### 저장 권장 경로

노트북에는 다음 파일명으로 저장하는 코드가 있으나 현재 로컬에서 파일은 확인되지 않았다.

```text
comtrade_monthly_2020_2024_russia_7210_8542.csv
```

재현성과 경로 일관성을 위해 다음 위치를 권장한다.

```text
data/interim/comtrade_monthly_2020_2024_russia_7210_8542.csv
data/processed/russia_trade_shift_summary_2020_2024.csv
data/processed/russia_trade_missing_summary_2020_2024.csv
```

## 현재 비어 있는 데이터 영역

| 경로 | 상태 | 비고 |
|---|---|---|
| `data/interim` | `.gitkeep`만 있음 | API 수집 중간 산출물 저장 권장 |
| `data/processed` | `.gitkeep`만 있음 | 분석 요약 테이블 저장 권장 |

## 관리 원칙

- 원천 파일은 `data/raw`에 보존하고 직접 수정하지 않는다.
- API 재수집 결과는 `data/interim`에 저장한다.
- 결측 처리, 국가명 표준화, 제재 전후 요약 결과는 `data/processed`에 저장한다.
- 외부 API 데이터는 수집 시점, 파라미터, 실패 국가/연도를 함께 기록한다.
- 한국어 CSV는 인코딩을 명시한다. 현재 원천 CSV는 `encoding="cp949"`로 읽어야 한다.
